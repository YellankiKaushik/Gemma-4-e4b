# Changelog

All notable release-level changes are summarized here. This project does not publish automatically from the repository.

## v0.1.1 - Release Candidate

- Premium Apple-inspired visual redesign.
- Improved typography, spacing, navigation, chat messages, and composer.
- Refined Light and Dark themes.
- Better runtime and error states.
- Improved responsive Side Panel behavior.
- Accessibility and reduced-motion improvements.
- No changes to the local-only architecture or Chrome permissions.

Release notes: [docs/releases/v0.1.1/GITHUB_RELEASE.md](docs/releases/v0.1.1/GITHUB_RELEASE.md)

## v0.1.0

- Initial local Chrome Side Panel release.
- Ollama model discovery and streaming chat.
- Stop generation support.
- IndexedDB conversation history.
- `chrome.storage.local` settings.
- Loopback-only Ollama host permissions.

Release notes: [docs/releases/v0.1.0/GITHUB_RELEASE.md](docs/releases/v0.1.0/GITHUB_RELEASE.md)
