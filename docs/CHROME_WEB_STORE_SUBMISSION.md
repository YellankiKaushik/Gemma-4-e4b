# Chrome Web Store Submission

Do not publish automatically. The Chrome Web Store submission is a manual maintainer action.

## Manual Process

1. Create or verify the Chrome Web Store developer account.
2. Enable required account security.
3. Create a new item.
4. Upload:

```text
Local-AI-Side-Panel-0.1.1.zip
```

5. Complete the Store Listing.
6. Upload assets:

- 128x128 store icon
- 3 screenshots
- 440x280 promotional tile

7. Complete Privacy Practices.
8. Add support information.
9. Add privacy policy URL.
10. Review permission justifications.
11. Save draft.
12. Run production-ID test.
13. Submit for review.
