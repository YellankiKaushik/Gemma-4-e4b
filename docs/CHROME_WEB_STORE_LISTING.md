# Chrome Web Store Listing Draft

## Product Name

Local AI Side Panel

## Short Description

Chat with local Ollama models from Chrome's side panel. Private, streaming, and fully local.

## Detailed Description

Local AI Side Panel puts your locally running AI models directly inside Chrome.

No cloud API keys. No remote inference backend. Your prompts are sent to Ollama running on your own computer.

Features:

- Chrome Side Panel interface
- Local Ollama model discovery
- Streaming responses
- Stop generation
- Multiple conversations
- Local chat history
- Model selection
- System prompt
- Temperature and history controls
- Light, Dark, and Auto themes
- Export and clear history

Requirements:

- Ollama installed and running
- at least one compatible local model

Recommended model:

- Gemma 4 E4B

Privacy:

- chats stored locally
- inference sent only to localhost / 127.0.0.1
- no project cloud backend
