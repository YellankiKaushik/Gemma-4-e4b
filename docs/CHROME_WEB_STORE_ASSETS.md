# Chrome Web Store Assets

## Required / Planned Assets

Store icon:

- 128x128 px

Screenshots:

- 1280x800 px
- at least 1 required
- prepare 3 polished screenshots

Small promotional tile:

- 440x280 px

Optional marquee:

- 1400x560 px

## Recommended Screenshot Set

Screenshot 1:

- Main chat in Dark mode
- Caption concept: "Run local AI directly beside your browser."

Screenshot 2:

- Settings / model selection / Light mode
- Caption concept: "Choose your local model and customize your experience."

Screenshot 3:

- Conversation history + local runtime status
- Caption concept: "Private conversations stored on your device."

Every screenshot should show actual current features. Do not show mock features or future roadmap items.

## Brand Icon Guidelines

Do not use:

- Google's Gemma logo
- Ollama llama logo
- Google Chrome logo
- copied third-party marks

Desired icon direction:

- simple geometric/local-network motif
- minimal side-panel shape
- subtle AI/spark/node element
- readable at 16x16
- independent brand identity
- works on light and dark surfaces

The current placeholder icons are acceptable for development packaging, but final icon creation remains a manual asset task before Chrome Web Store submission.
