# Local AI Side Panel v0.1.0

The first public release of Local AI Side Panel.

Local AI Side Panel provides a clean Chrome Side Panel interface for chatting with AI models running locally through Ollama.

## Highlights

- Chrome Manifest V3 Side Panel
- Direct local Ollama integration
- Automatic local model discovery
- Streaming responses
- Stop generation
- Multiple conversations
- Persistent local chat history
- Conversation rename and deletion
- JSON export
- System prompt controls
- Temperature and history controls
- Light, Dark, and Auto themes
- Dynamic Ollama extension-origin setup
- Loopback-only Ollama connectivity
- No project cloud inference backend

## Requirements

- Google Chrome 116+
- Ollama
- At least one compatible local model

Gemma 4 E4B is recommended, but other compatible Ollama chat models can also be used.

See the README and installation documentation for setup instructions.

## Privacy

Chats and settings are stored locally in Chrome.

AI inference is sent directly to Ollama running on your own computer.

Local AI Side Panel does not use a project-controlled cloud inference backend.
