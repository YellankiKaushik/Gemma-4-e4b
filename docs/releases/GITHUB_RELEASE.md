# GitHub Release

Create the GitHub Release manually after final QA passes.

## Manual Steps

1. Open the repository on GitHub.
2. Go to **Releases**.
3. Select **Draft a new release**.
4. Use this tag:

```text
v0.1.1
```

5. Use this title:

```text
Local AI Side Panel v0.1.1
```

6. Attach this file:

```text
release/Local-AI-Side-Panel-0.1.1.zip
```

7. Use this release body:

```text
docs/releases/v0.1.1/GITHUB_RELEASE.md
```

8. Mark as the latest release if appropriate.
9. Publish only after the exact ZIP QA checklist passes.

Do not claim the release exists until a maintainer creates it.
